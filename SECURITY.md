# Security policy

## Supported versions

Only the latest release is supported. Until v1, every Bouncer release is a prerelease, and fixes ship in the next release instead of as patches to older ones.

## Reporting a vulnerability

Please do not report security problems in a public issue. Report them privately with GitHub's private vulnerability reporting:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Fill in the form. It stays visible only to the maintainer and to you.

Or go directly to [report a vulnerability](https://github.com/shankar-sachin/get-bouncer/security/advisories/new).

Include:

- the Bouncer version (**Settings → About**) and your operating system
- what the problem is, and what an attacker could do with it
- the steps to reproduce it, and a proof of concept if you have one
- a workaround, if you know of one

Remove private text, keys and tokens from any logs or files you attach.

Bouncer's application source is not in this repository. Reports about the app, the installers and the install scripts are all welcome here.
