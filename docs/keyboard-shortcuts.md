# Keyboard shortcuts

These shortcuts work across Bouncer. On macOS the main modifier is <kbd>⌘</kbd> (Command). On Windows and Linux, use <kbd>Ctrl</kbd> in its place. The tables below list both.

## Everywhere

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Open the command palette | <kbd>⌘</kbd> <kbd>K</kbd> | <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Open the command palette (always opens, never closes) | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>P</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>P</kbd> |
| Open settings | <kbd>⌘</kbd> <kbd>,</kbd> | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| Show or hide the activity bar labels | <kbd>⌘</kbd> <kbd>B</kbd> | <kbd>Ctrl</kbd> <kbd>B</kbd> |

## Switching surfaces

| Surface | macOS | Windows and Linux |
| --- | --- | --- |
| Chat | <kbd>⌘</kbd> <kbd>1</kbd> | <kbd>Ctrl</kbd> <kbd>1</kbd> |
| Code | <kbd>⌘</kbd> <kbd>2</kbd> | <kbd>Ctrl</kbd> <kbd>2</kbd> |
| IDE | <kbd>⌘</kbd> <kbd>3</kbd> | <kbd>Ctrl</kbd> <kbd>3</kbd> |
| Rebound | <kbd>⌘</kbd> <kbd>4</kbd> | <kbd>Ctrl</kbd> <kbd>4</kbd> |
| Marketplace | <kbd>⌘</kbd> <kbd>6</kbd> | <kbd>Ctrl</kbd> <kbd>6</kbd> |

Studio (<kbd>⌘</kbd> <kbd>5</kbd>, <kbd>Ctrl</kbd> <kbd>5</kbd>) is coming later. Code is also reached with the **Chat | Code** toggle in the title bar.

## Chat

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| New chat | <kbd>⌘</kbd> <kbd>N</kbd> | <kbd>Ctrl</kbd> <kbd>N</kbd> |
| Show or hide the chats sidebar | <kbd>⌘</kbd> <kbd>\</kbd> | <kbd>Ctrl</kbd> <kbd>\</kbd> |
| Send message | <kbd>Enter</kbd> | <kbd>Enter</kbd> |
| New line in the composer | <kbd>Shift</kbd> <kbd>Enter</kbd> | <kbd>Shift</kbd> <kbd>Enter</kbd> |
| Stop generating | <kbd>Esc</kbd> | <kbd>Esc</kbd> |
| Save an edited message | <kbd>⌘</kbd> <kbd>↵</kbd> | <kbd>Ctrl</kbd> <kbd>Enter</kbd> |
| Cancel editing a message | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

## Code and approvals

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Send message | <kbd>Enter</kbd> | <kbd>Enter</kbd> |
| New line in the composer | <kbd>Shift</kbd> <kbd>Enter</kbd> | <kbd>Shift</kbd> <kbd>Enter</kbd> |
| Cycle mode | <kbd>Shift</kbd> <kbd>Tab</kbd> | <kbd>Shift</kbd> <kbd>Tab</kbd> |
| Approve the waiting step | <kbd>⌘</kbd> <kbd>↵</kbd> | <kbd>Ctrl</kbd> <kbd>Enter</kbd> |
| Deny the waiting step | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

Shift <kbd>Tab</kbd> cycles through the modes in this order: plan, manual, accept edits, autopilot. It works on the Code and IDE surfaces when the focus is in the composer or on the page.

## Menus and lists

| Action | Keys |
| --- | --- |
| Move through the slash command menu | <kbd>↑</kbd> <kbd>↓</kbd> |
| Fill in the highlighted command | <kbd>Tab</kbd> or <kbd>Enter</kbd> |
| Close the slash command menu | <kbd>Esc</kbd> |
| Move through the file mention menu (`@`) | <kbd>↑</kbd> <kbd>↓</kbd> |
| Pick the highlighted file | <kbd>Enter</kbd> or <kbd>Tab</kbd> |
| Move through the conversations list | <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Home</kbd> <kbd>End</kbd> |
| Rename the selected conversation | <kbd>F2</kbd> |
| Delete the selected conversation (asks to confirm) | <kbd>Delete</kbd> or <kbd>Backspace</kbd> |
| Clear the chat search | <kbd>Esc</kbd> |

## IDE

These work in the IDE when a folder is open.

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Quick open a file | <kbd>⌘</kbd> <kbd>P</kbd> | <kbd>Ctrl</kbd> <kbd>P</kbd> |
| Open the file in the quick open list to the side | <kbd>⌘</kbd> <kbd>Enter</kbd> | <kbd>Ctrl</kbd> <kbd>Enter</kbd> |
| Save the file | <kbd>⌘</kbd> <kbd>S</kbd> | <kbd>Ctrl</kbd> <kbd>S</kbd> |
| Close the tab | <kbd>⌘</kbd> <kbd>W</kbd> | <kbd>Ctrl</kbd> <kbd>W</kbd> |
| Split the editor | <kbd>⌘</kbd> <kbd>\</kbd> | <kbd>Ctrl</kbd> <kbd>\</kbd> |
| Show or hide the terminal panel | <kbd>⌘</kbd> <kbd>J</kbd> | <kbd>Ctrl</kbd> <kbd>J</kbd> |
| Commit from the source control box | <kbd>⌘</kbd> <kbd>Enter</kbd> | <kbd>Ctrl</kbd> <kbd>Enter</kbd> |
| Copy in the terminal | <kbd>⌘</kbd> <kbd>C</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>C</kbd> |
| Paste in the terminal | <kbd>⌘</kbd> <kbd>V</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>V</kbd> |

In the terminal, plain <kbd>Ctrl</kbd> <kbd>C</kbd> still reaches the shell on Windows and Linux. On Windows and Linux, <kbd>Ctrl</kbd> <kbd>J</kbd> and <kbd>Ctrl</kbd> <kbd>P</kbd> still toggle the panel and open quick open from inside the terminal.
