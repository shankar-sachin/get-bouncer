# Bouncer documentation

Bouncer runs open models on your own computer, so chats and files stay local. These pages cover how to install it, how to use each part, and where to get help.

## Start

- [Getting started](getting-started.md): install, first launch, your first model and your first chat.
- [Install](install.md): one-line installers, manual downloads, checksums and uninstalling.
- [Updates](updates.md): how Bouncer gets new versions on each system.
- [System requirements](system-requirements.md): supported systems, memory and graphics backends.

## Use Bouncer

- [Chat](chat.md): talk with a model you have loaded.
- [Rebound](rebound.md): make bots, each with its own room of chats.
- [Bouncer Code](code.md): work on a folder with a model, with changes you review before they apply.
- [Scheduled tasks](scheduled-tasks.md): run a prompt in a folder later, and review its changes.
- [IDE](ide.md): edit a folder in an editor, with Bouncer Code docked beside it.
- [Models](models.md): find, download, load and tune models.

- [Privacy](privacy.md): what stays on your machine and what connects to the internet.
